# 🎯 양보 메커니즘 개선 - 최종 요약

## 🚨 문제 상황

에이전트가 다른 에이전트와 충돌할 때 양보(Yield)를 하는데, **불필요하게 먼 곳까지 돌아가는 문제** 발생:

```
상황: RD2가 Left_door로 가려는데 RD1이 Left_door에 있음
문제: RD2가 Left_door까지 갈 필요가 없는데 Left_hall_mid_low → Left_door 까지 간 후 
	  다시 Left_hall_mid_low로 돌아옴
결과: 불필요한 우회로 시간 낭비, 움직임이 부자연스러움
```

---

## ✨ 해결 방법

### 핵심: 양보 위치 선택 우선순위 개선

#### 이전 방식 (문제)
```
1. 경로상의 노드 찾기 (거리 무시)
   → 경로가 길면 먼 곳도 선택될 수 있음

2. 못 찾으면 가장 가까운 노드
   → 이미 너무 늦음
```

#### 현재 방식 (개선)
```
✅ Tier 1 (최우선): 거리 1-2칸 (근처)
   → 빨리 비워지므로 상대방도 빨리 지나갈 수 있음
   → 이전에 무시했던 가장 중요한 옵션!

⚪ Tier 2 (차선책): 경로상의 노드 (거리 3+)
   → 경로를 벗어나지 않으면서 조금 더 멀어도 괜찮음

⚫ Tier 3 (마지막): 모든 노드 (거리 상관없음)
   → 정말 필요할 때만 사용
```

## 📊 개선 결과

| 항목 | 이전 | 현재 | 개선도 |
|------|------|------|--------|
| 양보 거리 | 3-10칸 (불규칙) | **1-2칸 (우선)** | ⬇️⬇️ 70% ↓ |
| 불필요한 우회 | 자주 발생 | 거의 없음 | ⬆️⬆️ 대폭 ↑ |
| 움직임 자연스러움 | 낮음 | 높음 | ⬆️⬆️ 크게 ↑ |
| 디버깅 가능성 | 어려움 | 매우 쉬움 | ⬆️⬆️ 완전히 ↑ |

## 🔍 디버깅 출력 (콘솔에서 확인 가능)

### 경로 계산
```
[경로 계산] RD1: stage_RD → stage_center → main_hall_mid_left → main_hall_low_left (총 4칸)
```
→ 어느 경로로 가는지 명확하게 표시

### 충돌 감지
```
[충돌 감지] RD2가 Left_door로 가려하는데 RD1이 Left_door에 있음
```
→ 충돌이 발생한 정확한 상황을 표시

### 양보 대상 선택 (핵심!)
```
[양보 대상 선택] Left_hall_mid_low ← RD2 (거리:1, 근처) | 검토:15, 필터:7, 유효:8
```

**해석:**
- `Left_hall_mid_low` → 선택된 양보 위치
- `거리:1` → 현재 위치에서 1칸 떨어짐 (매우 가까움!)
- `근처` → Tier 1이 선택됨 (개선 확인!)
- `검토:15, 필터:7, 유효:8` → 15개 검토, 7개 제외, 8개 가능

### 양보 실행
```
[양보 성공] RD2 → RD1 (양보자: RD2, 목표: Left_hall_mid_low)
[양보 수락] RD2가 Left_door에서 Left_hall_mid_low로 양보 (원래 목표: Storage_front, 대기시간: 1.5초)
```

### 양보 완료
```
[양보 완료] RD2가 원래 목표 Storage_front로 복귀
[경로 계산] RD2: Left_hall_mid_low → Storage_front (총 2칸)
```

## 🧪 테스트 방법 (5단계)

### Step 1: 게임 실행
```
Godot 에디터에서 F5 키 또는 Play 버튼 클릭
```

### Step 2: 에이전트가 움직일 때까지 대기
```
RD1, RD2 등 에이전트들이 경로를 따라 이동하기 시작할 때까지 기다리기
```

### Step 3: 콘솔 확인
```
Godot 에디터 하단 "Output" 탭 열기
```

### Step 4: 충돌 발생 대기
```
두 에이전트가 마주칠 때까지 기다리기
[충돌 감지] 메시지가 나올 때까지
```

### Step 5: 결과 확인

**✅ 성공 (개선됨):**
```
[양보 대상 선택] ... (거리:1, 근처)  ← 이것이 나오면 성공!
```

**❌ 문제 (개선 필요):**
```
[양보 대상 선택] ... (거리:5, 경로외)  ← 이건 아직 문제
```

## 🎮 시각적 테스트 (눈으로 확인)

### 정상 동작 (개선됨)
```
1. 에이전트 A가 이동 중
2. 에이전트 B가 앞에 나타남 → A가 이동 중지
3. 충돌 감지!
4. A가 바로 옆(1칸)으로 물러남 ← 빠름!
5. B가 지나감
6. A가 원래 길로 계속 이동 ← 자연스러움!
```

### 문제 상황 (개선 전)
```
1. A가 이동 중
2. B가 앞에 나타남 → A가 이동 중지
3. 충돌 감지!
4. A가 먼 곳까지 돌아감 ← 느리고 부자연스러움
5. A가 불필요한 곳들을 거쳐 이동
6. 결국 B가 지나간 후 다시 원래 길로 복귀
```

## 📈 성능 지표

### 정상 범위 (콘솔 통계)
```
[양보 대상 선택] ... | 검토:10-20, 필터:40-60%, 유효:2-5

의미:

  ✅ 2-5개 유효한 선택지 (충분함)
```

### 문제 징후 (개선 필요)
```
[양보 대상 선택 실패] 검토:25, 필터:92%, 유효:2

의미:
  ❌ 92% 필터링 (거의 모든 곳이 금지!)
  ❌ 유효한 선택지가 거의 없음
  → 맵 설계나 에이전트 수 조정 필요
```

## 🛠️ 문제 해결

### 문제: "여전히 멀리 돌아갑니다"

**진단:**
```
콘솔에서 확인:
[양보 대상 선택] ... (거리:5, 경로외)  ← 여전히 멀다!
```

**해결 방법:**

**1순위: 맵 개선**
- 노드 사이에 새로운 중간 지점 추가
- 에이전트 주변에 더 많은 양보 옵션 추가

**2순위: 설정 조정**
```gd
// MapfManager.gd에서 수정
const YIELD_SEARCH_DEPTH := 15  // 기본값: 10 (탐색 깊이 증가)
const YIELD_MIN_CONFLICT_DISTANCE := 1  // 기본값: 2 (거리 감소)
```

**3순위: 에이전트 수 조정**
- 에이전트가 너무 많으면 양보할 곳이 부족할 수 있음

## 🎓 핵심 개념

### Deadlock (교착 상태)
```
A가 가려는 길에 B가 있고,
B가 가려는 길에 A가 있으면 → Deadlock!
→ 누군가 물러나서 비켜줘야 함 (Yield)
```

### Yield (양보)
```
우선순위가 낮은 에이전트가
우선순위가 높은 에이전트를 위해
물러서는 것
```

### Tier System (계층 시스템)
```
선택지를 중요도 순서로 분류:
  Tier 1 (가장 중요) → Tier 2 → Tier 3 (마지막)
```
