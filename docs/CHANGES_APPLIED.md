# 적용된 변경사항 (Changes Applied)

## 📌 개요

양보(Yield) 메커니즘의 불필요한 우회 문제를 해결하고, 전체 디버깅 출력을 개선했습니다.

## 📂 수정된 파일

### 1. `res://Scripts/Autorun/MapfManager.gd`

#### 수정 1: try_resolve_deadlock 함수에 디버깅 출력 추가 (Line 122-147)

**변경 내용:**
- 양보할 위치를 찾지 못했을 때 상세 메시지 출력
- 양보 성공/거부 시 상세 정보 출력

**출력 예시:**
```
[충돌] RD1이 RD2를 막고 있음 → RD2가 양보할 위치를 찾을 수 없음
[양보 성공] RD2 → RD1 (양보자: RD2, 목표: Left_hall_mid_low)
[양보 거부] RD2가 양보를 거부함 (목표: Left_hall_mid_low)
```

#### 수정 2: _find_yield_target 함수 완전 개선 (Line 164-267)

**변경 내용:**
1. **우선순위 로직 개선**
   - Tier 1: 거리 1-2 (최우선!) ← **핵심 개선**
   - Tier 2: 경로상의 노드
   - Tier 3: 모든 노드

2. **상세 디버깅 통계 추가**
   - 검토한 후보 수
   - 필터링된 노드 수
   - 실제 유효한 노드 수
   - 경로상 노드 수

3. **결과 출력 개선**
   ```
   [양보 대상 선택] Left_hall_mid_low ← RD2 (거리:1, 근처) | 검토:15, 필터:7, 유효:8
   [양보 대상 선택 실패] 검토:20개, 필터:18개, 유효:2개, 경로상:0개
   ```

### 2. `res://Scripts/Class/animatronics.gd`

#### 수정 1: 경로 출력 개선 (Line 311-319)

**변경 전:**
```gd
print(move_path, " 경로 출력  ", self.name)
```

**변경 후:**
```gd
# 경로 출력 (가독성 개선)
var path_names: Array[String] = []
for node in move_path:
    if node is Movepoint:
        path_names.append(node.name)
var path_str: String = " → ".join(path_names)
print("[경로 계산] %s: %s (총 %d칸)" % [self.name, path_str, move_path.size()])
```

**출력 예시:**
```
[경로 계산] RD1: stage_RD → stage_center → main_hall_mid_left → main_hall_low_left (총 4칸)
```

#### 수정 2: 충돌 감지 시 출력 추가 (Line 469-481)

**변경 내용:**
- 충돌이 처음 감지될 때만 한 번 출력
- 어느 에이전트가 어디로 가려고 하는지 명확히 표시

**출력 예시:**
```
[충돌 감지] RD2가 Left_door로 가려하는데 RD1이 Left_door에 있음
```

#### 수정 3: 양보 수락 시 상세 정보 출력 (Line 331-346)

**변경 내용:**
- 현재 위치, 양보할 위치, 원래 목표, 대기시간 표시

**출력 예시:**
```
[양보 수락] RD2가 Left_door에서 Left_hall_mid_low로 양보 (원래 목표: Storage_front, 대기시간: 1.5초)
```

**수정 상세:**
- `_enum_to_string` 함수 대신 `PIN_NODE_NAMES` 딕셔너리 사용
- 형식: `PIN_NODE_NAMES.get(_main_goal_pin, "Unknown")`

#### 수정 4: 양보 완료 후 복귀 시 출력 추가 (Line 415-422)

**변경 내용:**
- 대기 시간이 끝나고 원래 목표로 돌아갈 때 출력

**출력 예시:**
```
[양보 완료] RD2가 원래 목표 Storage_front로 복귀
```

## 🎯 핵심 개선사항

### 문제점 (Before)
```
Left_door 충돌 발생
  → Left_door까지 갈 필요가 없는데 Left_hall_mid_low → Left_door 까지 검색
  → 불필요한 우회로 시간 낭비
  → 최대 5-10칸까지 돌아감
```

### 해결책 (After)
```
Left_door 충돌 발생
  → 현재 위치에서 가장 가까운 안전한 곳 (1-2칸) 우선 선택
  → 필요시 경로상의 노드 (3+칸)
  → 정말 필요할 때만 먼 곳 (5+칸)
  → 최소 1-2칸만 이동 (빠르고 자연스러움)
```

## 🔍 출력 메시지 색인

### 전체 메시지 목록

| 메시지 | 발생 시점 | 의미 |
|--------|---------|------|
| `[경로 계산]` | 에이전트가 새 경로 계산 | 경로 정보 및 길이 표시 |

## 📝 추가 참고사항

### 주요 개선 지점

1. **Tier 1 우선순위 (거리 1-2)**
   - 이전: 경로상 노드를 먼저 찾으려고 함
   - 현재: 가장 가까운 곳을 먼저 찾음 ← **핵심 개선**

2. **통계 정보**
   - 후보 검토 수: 얼마나 많은 노드를 살펴봤는지
   - 필터링 수: 조건 때문에 제외된 노드
   - 유효 수: 실제 선택 가능한 노드
   - 경로상 수: 원래 경로와 겹치는 노드

3. **가독성**
   - 화살표(`→`)로 경로 방향 시각화
   - 모든 메시지에 에이전트 이름 명시
   - 시간 정보 포함 (대기시간 등)

### 성능 영향

- **메모리**: 무시할 수 있는 수준 (몇 KB)
- **CPU**: 출력 오버헤드만 (게임 플레이에 미미)
- **디스크**: 영향 없음

## 📌 요약

**문제:** 에이전트가 양보할 때 불필요하게 멀리 돌아가는 문제  
**원인:** 양보 대상 선택이 경로상의 노드만 우선하여 거리를 무시함  
**해결:** 거리 1-2의 가장 가까운 곳을 최우선으로 선택하는 Tier 시스템 도입  
**효과:** 양보 거리 1-2칸으로 단축 + 자연스러운 움직임  
**디버깅:** 모든 단계를 명확한 한국어로 출력하여 문제 추적 용이
