## 🔧 1단계: 경로 출력 개선

### 이전
```
[stage_RD, stage_center, main_hall_mid_left, main_hall_low_left] 경로 출력  RD1
```

### 현재
```
[경로 계산] RD1: stage_RD → stage_center → main_hall_mid_left → main_hall_low_left (총 4칸)
```

**장점:**
- 노드 이름이 명확하게 보임
- 화살표로 진행 방향이 직관적
- 경로의 길이를 숫자로 표시
- 어느 에이전트인지 명확

## 🎯 2단계: 충돌 감지 출력 추가

### 새로운 출력
```
[충돌 감지] RD2가 Left_door로 가려하는데 RD1이 Left_door에 있음
```

**언제 출력되는가:**
- 에이전트가 다음 노드로 이동하려고 할 때
- 그 위치에 다른 에이전트가 있을 때
- **처음 충돌이 감지되는 순간에만 한 번** 출력 (반복 출력 안 함)

**정보 확인 방법:**
```
[충돌 감지] {피하려는 에이전트}가 {목표 노드}로 가려하는데 {현재 있는 에이전트}가 {그 노드}에 있음
```

## 💡 3단계: 양보 대상 선택 로직 개선

### 문제점 (이전)
```
문제: Left_door까지 갈 필요가 없는데 Left_hall_mid_low → Left_door → ... 까지 갔다가 
	  다시 Left_hall_mid_low로 돌아옴

원인: 경로상의 노드를 찾으려고 했지만, 경로가 길어서 불필요한 우회 발생
```

### 해결책 (현재)
```
우선순위 변경:
  Tier 1 (최우선): 아주 가까운 곳 (거리 1-2칸)
	→ 빨리 비워지므로 상대방도 빨리 지나갈 수 있음
	
  Tier 2 (차선책): 경로상의 노드 (거리 3+)
	→ 경로를 벗어나지 않음
	
  Tier 3 (마지막): 모든 노드 (거리 상관없음)
	→ 정말 필요할 때만
```

### 새로운 출력 예시

#### 성공적인 양보 대상 선택
```
[양보 대상 선택] Left_hall_mid_low ← RD2 (거리:1, 근처) | 검토:15, 필터:7, 유효:8
```

**해석:**
- `Left_hall_mid_low` → RD2가 여기로 이동할 위치
- `거리:1` → 현재 위치에서 1칸 떨어짐 (매우 가까움!)
- `근처` → Tier 1 (최우선 선택됨)
- `검토:15` → 15개 후보를 검토함
- `필터:7` → 7개 제외 (금지 구역 등)
- `유효:8` → 8개가 조건을 만족함

#### 실패 사례
```
[양보 대상 선택 실패] 검토:20개, 필터:18개, 유효:2개, 경로상:0개
```

**원인:**
- 주변이 모두 금지 구역이거나 다른 에이전트로 가득 찼을 수 있음
- 맵 설계 문제일 수 있음

## ✅ 4단계: 양보 수행 과정 추적

### 양보 성공
```
[양보 성공] RD2 → RD1 (양보자: RD2, 목표: Left_hall_mid_low)
```

**의미:**
- 양보 요청이 수락됨
- RD2가 RD1에게 길을 비워줌

### 양보 실행 시작
```
[양보 수락] RD2가 Left_door에서 Left_hall_mid_low로 양보 (원래 목표: stage_RD, 대기시간: 1.5초)
```

**필드:**
| 필드 | 의미 |
|------|------|
| `RD2` | 양보하는 에이전트 |
| `Left_door` | 현재 위치 |
| `Left_hall_mid_low` | 양보할 위치 (이동할 곳) |
| `stage_RD` | 원래 최종 목표 (양보 후 돌아갈 곳) |
| `1.5초` | 양보 위치에서 대기할 시간 |

### 양보 완료
```
[양보 완료] RD2가 원래 목표 stage_RD로 복귀
```

**의미:**
- 대기 시간이 끝남
- 에이전트가 원래 목표로 경로를 다시 계산하여 이동 시작

## 🐛 문제 진단 가이드

### 문제: "양보를 해도 여전히 멀리 돌아간다"

#### 1단계: 출력 확인
```
[양보 대상 선택] Left_door ← RD2 (거리:5, 경로외)
```

**진단:**
- `거리:5` → 5칸 떨어짐 (너무 멀다!)
- `경로외` → 원래 경로와 무관 (불필요한 우회!)

#### 2단계: 원인 분석

**가능한 원인들:**
1. **Tier 1 (근처) 옵션이 없음**
   - 블로커 주변이 모두 금지 구역
   - 다른 에이전트로 가득 찬 상황

2. **경로상의 노드가 모두 거리 3+ 이상**
   - 경로가 길어서 Tier 2도 실제로는 먼 곳

3. **맵 설계 문제**
   - 노드 배치가 너무 넓음
   - 연결 구조가 복잡함

#### 3단계: 개선 방법

```gd
// 1. 검색 깊이 증가 (더 많은 옵션 찾기)
const YIELD_SEARCH_DEPTH := 15  // 기본값: 10

// 2. 충돌 회피 거리 감소 (더 가까운 곳도 가능)
const YIELD_MIN_CONFLICT_DISTANCE := 1  // 기본값: 2

// 3. 맵에 더 많은 노드 추가 (선택지 증가)
// 또는 기존 노드 사이에 새로운 중간 지점 추가
```

## 📈 성능 확인 지표

### 정상 범위

```
[양보 대상 선택] ... | 검토:10-20, 필터:40-60%, 유효:2-5

해석:
  검토:       10-20개 (맵 크기에 따라 다름)
  필터 비율:  40-60% 정도 (너무 많으면 맵이 복잡함)
  유효:       최소 2-3개 (선택지가 있어야 함)
```

### 문제 징후

```
[양보 대상 선택 실패] 검토:25개, 필터:23개, 유효:2개

해석:
  필터:       92% (거의 모든 곳이 금지!)
  유효:       겨우 2개 (선택지가 거의 없음)
  
→ 이것은 맵 설계나 에이전트 수의 문제일 수 있음
```

## 🎮 테스트 방법

### 1. 콘솔 출력 확인
```
게임 실행 → 에이전트가 이동하도록 대기 → 콘솔 확인

찾아야 할 패턴:
  ✓ [경로 계산] ... (처음 시작)
  ✓ [충돌 감지] ... (충돌 발생 시)
  ✓ [양보 대상 선택] ... (거리:1-2, 근처) ← 이것이 나오면 개선됨!
  ✓ [양보 성공] ...
  ✓ [양보 수락] ...
  ✓ [양보 완료] ...
```

### 2. 시각적 테스트
```
게임 플레이 중 관찰:

✓ 정상 (개선된 상태):
  - A가 가려는 길을 B가 막음
  - A가 바로 옆으로 1칸 물러남 (빠름!)
  - B가 지나감
  - A가 계속 가던 길로 이동

✗ 문제 상황 (개선 전):
  - A가 양보하려고 멀리 돌아감
  - A가 불필요한 곳을 거쳐감
  - 시간이 너무 오래 걸림
```

### 3. 경로 길이 확인

**이전 (문제):**
```
[경로 계산] RD2: Left_door → Left_hall_mid_low → Storage_front → ... (총 10칸) ← 길다!
```

**현재 (개선):**
```
[경로 계산] RD2: Left_hall_mid_low (양보 위치, 총 2칸) ← 짧다!
```

## 🔍 로그 분석 팁

### 특정 에이전트만 추적
```
1. 콘솔 검색 기능 사용
2. "RD1" 검색 → RD1만 관련된 출력 보기
3. "충돌" 검색 → 충돌 관련 출력만 보기
```

### 타임라인 이해
```
시간 순서로 보기:
1. [경로 계산] ... ← 가장 먼저 경로 계산
2. [충돌 감지] ... ← 시간이 지나다가 충돌 발생
3. [양보 대상 선택] ... ← 바로 양보 대상 선택
4. [양보 성공] ... ← 양보 수락
5. [양보 수락] ... ← 실제 이동 시작
6. (대기 시간 경과)
7. [양보 완료] ... ← 대기 완료, 복귀
```

## 📞 트러블슈팅

### "출력이 안 나옵니다"
```
→ 게임이 실행 중인지 확인
→ 에이전트가 실제로 이동하는지 확인

```
→ 콘솔 필터 사용: "[양보", "[충돌", "[경로"

```

### "여전히 불필요하게 돌아갑니다"
```
→ [양보 대상 선택] 출력의 "거리" 값 확인
→ 거리가 3+이면 맵 개선 필요
→ YIELD_SEARCH_DEPTH 증가 시도
